Daily CSV files are organized as `channel/year/month/YYYY-MM-DD.csv`. Follow the channel indexes below, then a month, to browse daily files. Days without messages have no CSV file.

Each UTF-8 CSV has three columns: `date/time`, `nick`, `message`. Timestamps use `YYYY-MM-DD HH:MM:SS` exactly as recorded. Messages are chronological, with original log ID breaking ties. Standard CSV quoting preserves commas, quotes, and embedded newlines.

Only public messages (`Type = 1` in the original viewer) are included. Join, leave, quit, kick, and other events are excluded. Nicknames reflect the recorded sender rather than a merged alias.
